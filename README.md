## Sobre

**Engenheiro Florestal** (UFSJ, 2025) e **Cientista de Dados Geoespaciais**, com base sólida em back-end. Automatizo pipelines de dados ambientais com **Python** e **Google Earth Engine**, sirvo os resultados por APIs em **FastAPI** ou **Node.js/TypeScript** e entrego tudo como WebMaps e dashboards que substituem PDFs estáticos.

- **Hoje:** cientista de dados na **EnvironBIT** (projeto CNPq) e consultor de geoprocessamento na **Vimef Engenharia** (linhas de transmissão e compensação ambiental).
- **Formação:** pós-graduação em Ciência de Dados na Data Science Academy.
- **Foco:** ETL geoespacial, sensoriamento remoto, machine learning florestal, WebGIS e APIs.
